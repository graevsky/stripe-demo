## Запуск через Docker

###

1) Создать `.env` в папке рядом с `docker-compose.yml`  на основе [.env.example](./.env.example)
2) Запустить контейнер с помощью `docker compose up --build`
3) Создать админа Django с помощью `docker compose exec web python manage.py createsuperuser`
4) Готово, панель доступна по <http://127.0.0.1:800/admin/>

## Запуск без Docker

Требуется `Python 3.13+`

1) Создать venv и активировать его:

```bash
python -m venv venv
# Windows:
venv\Scripts\Activate.ps1
# Linux:
source venv/bin/activate
```

2) Установить зависиомсти с помощью `pip install -r requirements.txt`
3) Создать `.env` в папке рядом с `docker-compose.yml`  на основе [.env.example](./.env.example)
3) Создать миграции и суперпользователя:

```bash
python manage.py migrate
python manage.py createsuperuser
```

5) Запстить с помощью `pyton manage.py runserver`

## Возможности

После запуска можно:

### Через админку

- Создавать **Items** с валютой `USD` или `EUR`
- Создавать **Orders** и добавлять в них товары с количеством. В **Orders** так же можно добавить налоги\скидки
- Создавать **Discounts** и **Taxes**, привязывать их к заказам
- Проверять суммы заказа в админке:
  - `Subtotal` - До скидок\налогов
  - `Total` - После скидок\налогов

Про создание Discounts и Taxes дополнительная информация ниже

## Эндпоинты

Здесь описаны все эндпоинты, которые доступны в проекте.

### Item

- `GET /item/<id>/`  
  HTML-страница товара, его описания и кнопка Buy (`/buy/<id>/` и редирект в Checkout)
- `GET /buy/<id>/`  
  JSON вида `{ "id": "<stripe_checkout_session_id>" }`

### Order

- `GET /order/<id>/`  
  HTML-страница заказа. Содержит список товаров и кнопку Pay Order (`/buy-order/<id>/` и редирект в Checkout)
- `GET /buy-order/<id>/`  
  Возвращает JSON `{ "id": "<stripe_checkout_session_id>" }` для оплаты заказа целиком

При нажатии на Buy для Item откроется окно чекаута, которое не содержит налогов и скидок. Налоги\скидки будут корректно отображаться в чекауте только для Order.

## Как создавать данные

### Создание Item

1) Открыть админ панель и пройти по Shop -> Items -> Нажать `+`
2) Указать Имя, Описание, Стоимость, Валюту.

### Создание Discount

1) Для создания скидки нужно прежде всего получить ее ID в дешборде Stripe. Там указывается процент скидки, время действия и прочие ограничения. После чего пользователь может просмотреть ID скидки.
2) Открыть админ панель и пройти по Shop -> Discounts -> Нажать `+`
3) Указать Имя, ID скидки Stripe, процент скидки (для внутренних расчетов), статус скидки (активна или нет)

### Создание Tax

1) Для создания налога нужно прежде всего получить ID этого налога. Создать налог Stripe можно выполнив [create_tax.py](utils/create_tax.py). Здесь:

```py
tax_rate = stripe.TaxRate.create(
  display_name="VAT", # Имя налога, отображается в Checkout форме
  percentage=20.0, # Процент налога
  inclusive=False, # Включается ли налог в стоимость или нет
  country="NL", # Региональные ограничения (работоспособность не проверял)
  description="VAT", # Описание скидки
)
```

После выполнения программа выдаст id скидки вида `txr_xxx`

2) Открыть админ панель и пройти по Shop -> Taxs -> Нажать `+`
3) Указать Имя, ID налога Stripe, процент налога (для внутренних расчетов), включается ли налог в стоимость, статус налога (активен или нет)

P.S. Вероятно, налог можно создать и через дешборд страйп, но для этого возможно требуется полноценная (с указанием налоговой информации) регистрация аккаунта.

### Создание Order

1) Открыть админ панель и пройти по Shop -> Orders -> Нажать `+`
2) Выбрать нужные скидки
3) Выбрать нужные налоги
4) Добавить товары (можно редактировать товары по месту)
